# Монтаж Reels DEEV architects

Технический порядок работы с видео. Смысловые правила — в навыке `yuri-eremin-advisor` и в `reels/rules/`. Перед монтажом прочитать:

1. `reels/rules/01_Регламент_работы_с_Reels.md` — ежедневный регламент (обязательно).
2. `.claude/skills/yuri-eremin-advisor/references/montage.md` — монтаж, субтитры, звук.
3. `.claude/skills/yuri-eremin-advisor/references/method.md` и `direct-feedback.md` — хук, автор, клиент, призыв.

Общаться с пользователем по-русски.

## 1. Исходник с Google Диска

- Видео лежит в папке **iCloud** (id `1ONx34FlPatQqLUTKwFb8359PAkqcFQq5`). Найти файлы: `search_files` с `parentId = '<id папки>'`.
- MCP-инструмент `download_file_content` не отдаёт файлы больше 10 МБ. Если у файла доступ «anyone / reader», качать напрямую:
  `curl -sSL -o reels/source/<имя> "https://drive.usercontent.google.com/download?id=<fileId>&export=download&confirm=t"`
  и сверить размер с `fileSize`.
- `reels/source/` в `.gitignore`: исходники больше лимита GitHub (100 МБ), их всегда можно скачать заново.

## 2. Инструменты

- ffmpeg: `pip install imageio-ffmpeg`, путь — `imageio_ffmpeg.get_ffmpeg_exe()` (есть libx264, libass, loudnorm; drawtext нет — текст делать через ASS-субтитры).
- Расшифровка: `pip install faster-whisper`, модель `large-v3` (`small` ошибается в русской речи). Для спорных стыков расшифровывать короткий фрагмент отдельно.
- Шрифт: `reels/fonts/MontserratDEEV-*.ttf` (латиница + кириллица), подключать через `subtitles=...:fontsdir=reels/fonts`.
- iPhone пишет вертикальное видео как 1920×1080 с поворотом −90°: ffmpeg поворачивает сам, на выходе 1080×1920.
- В MOV с iPhone две звуковые дорожки: брать `0:a:0` (AAC), вторая — пространственный звук APAC.

## 3. Порядок монтажа

1. Раскадровка: лист кадров раз в секунду (`fps=1,scale=160:-1,tile=8x6`) — понять, что в кадре.
2. Расшифровка с таймкодами слов → таблица `фраза → визуальное доказательство → крупность → действие`.
3. Отбор фрагментов: убрать паузы, повторы, технические реплики, **обращения к зрителю на «ты/вы»** («смотрите», «на ваше здоровье») — регламент запрещает второе лицо.
4. Текст на экране:
   - хук сверху в первые ~3 с: проблема, обещание или позиция, без второго лица;
   - субтитры речи — в одной стабильной зоне, акцент только на ключевых словах;
   - в конце — имя бюро и одно уместное действие (контакт в профиле), если оно есть в речи.
5. Сборка скриптом (образец: `reels/2026-09-29_smesitel-gazirovannaya-voda/build.py`): trim/atrim по фрагментам, фейды звука 40–60 мс на стыках, concat, 30 fps, субтитры, `loudnorm=I=-14:TP=-1.5`, H.264 CRF 19, AAC 192k, `+faststart`.
6. Проверка: лист кадров готового ролика, полноразмерные кадры с текстом, повторная расшифровка готового звука — нет обрывков слов и следов вырезанных обращений.

## 4. Безопасная зона 1080×1920

- Сверху ~250 px и снизу ~420 px занимает интерфейс Instagram, справа ~140 px — кнопки.
- Субтитры: низ текста около y ≈ 1450 (ASS `Alignment 2`, `MarginV 470`), чтобы не закрывать рот в селфи-кадрах.
- Хук: `Alignment 8`, `MarginV 330`. Подпись бюро: `MarginV 270`, мелко, с разрядкой.

## 5. Стиль DEEV

- Спокойно и точно: без эффектов ради эффектов, одна гарнитура, белый текст с мягкой тенью, один тёплый акцентный цвет (`#E0C89C`).
- Субтитры не должны искажать речь. Если слово неразборчиво — не выдумывать, а сказать пользователю.
- Слово «клиент», не «заказчик». Не выдавать чужие материалы за работу бюро; бренды производителей не называть без подтверждения.
